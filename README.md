# Etumonu Collins Chukwueku

**Blockchain Development · Smart Contracts · Application Integrations**

I'm a software developer with a focus on blockchain development and the connection between smart contracts and usable applications. My interests span contract behavior, wallet interactions, and the feedback that helps people understand a transaction.

I'm drawn to the engineering questions behind these systems: Who can change a piece of state? What happens when a transaction fails? How can an application make permissions and outcomes clear before someone takes an action?

## What Interests Me

- **Smart contract logic** with explicit permissions and understandable state changes.
- **Wallet integrations** that explain connection, signing, and transaction outcomes.
- **Contract testing** that covers invalid inputs, access boundaries, and failure paths.
- **Application integrations** that connect on-chain behavior with useful interfaces.
- **Developer tooling** that makes contract interaction and debugging easier to follow.

| Area | Questions I Want to Explore |

## Development Priorities

- Start with a small contract and clearly defined behavior.
- Make authorization rules and assumptions visible in code and documentation.
- Test rejected actions and edge cases alongside successful transactions.
- Keep transaction feedback clear and avoid implying success before confirmation.
- Document setup, test procedures, and integration examples alongside the source.
